✅ Professional Reporting Style in Papers

A high-quality RL paper will usually include:

Analysis Type	Reporting
Linear Probing	Accuracy (%), plot predicted vs. true state
PCA / t-SNE	2D scatter plot, colored by action or reward
CCA	Canonical correlation scores, 1–N
Saliency	Heatmaps or attention over time
Memory Ablation	Line plot: performance vs. memory length
